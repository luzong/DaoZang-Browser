# 道藏全书目录浏览器

**一款纯静态、零依赖、本地离线可用的道藏文献目录浏览工具**

无需后端、无需服务器、无需联网，双击即可运行。支持海量道藏典籍秒开浏览、分批加载、全局检索、PDF 精准页码跳转，完美适配桌面/移动端，解决传统道藏目录翻阅卡顿、查找繁琐、跳转不便的问题。

## 📌 项目简介

本项目为**离线道藏文献阅览工具**，整合多版本道藏典籍资源，通过轻量化静态页面实现典籍目录可视化管理。针对超大目录数据做了极致优化，彻底解决大批量典籍加载卡顿、卡死问题，是道藏学习、研究、查阅的高效本地工具。

涵盖：正统道藏、藏外道书、道藏辑要、敦煌道藏、中华道藏、中华续道藏、庄林续道藏等全系列道藏资源。

## ✨ 核心特性

- **极速启动，秒级加载**：页面优先渲染书籍卡片，无需等待全部目录数据解析，打开即用，无空白等待。

- **分批渲染，永不卡顿**：所有典籍章节分批异步展开（默认每批5本），海量数据也能流畅浏览，底部实时展示加载进度。

- **全局跨库搜索**：支持全系列道藏典籍关键词检索，按经名精准匹配，结果独立展示，快速定位目标典籍。

- **PDF 精准跳转**：一键点击典籍条目，自动打开对应 PDF 并跳转至指定阅读页码，告别手动翻找。

- **灵活折叠导航**：支持单本典籍展开/折叠，顶部快捷导航一键定位，自动滚动并展开对应书籍目录。

- **纯静态零依赖**：仅由 HTML \+ JS 构成，无第三方依赖、无后端程序、无需数据库，本地离线运行。

- **全端适配**：自适应电脑、平板、手机等各类屏幕尺寸，移动端流畅触控操作。

## 🚀 快速使用教程

1. **解压文件**：将所有文件、文件夹解压至同一个根目录，切勿拆分、重命名核心文件。

2. **核对路径**：确保所有 PDF 资源文件夹与 `data.js` 内配置的路径完全一致。

3. **启动程序**：直接双击打开 `道藏全书目录浏览器.html`，无需联网、无需部署环境。

4. **开始使用**：支持浏览目录、关键词搜索、折叠展开、PDF 页码精准跳转等全部功能。

## ⚠️ 注意事项

- 请勿随意修改 `data.js` 文件名、文件路径及内部数据，否则会导致典籍匹配、跳转失效。

- PDF 文件夹名称、层级不可随意更改，需与数据源保持统一。

- 建议使用主流浏览器（Chrome、Edge、Firefox）打开，避免兼容性问题。

- 文件夹路径建议使用纯中文/英文，避免特殊符号、过长路径导致读取异常。
